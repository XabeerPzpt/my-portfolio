# Personal Developer Portfolio — Initial Development Plan

## 1. Project Objective

Build a modern, professional, responsive personal portfolio website using Next.js.

The immediate goal is to create a clean and attractive first version, deploy it to my personal domain, and then improve it incrementally.

Do not overcomplicate the initial implementation.

## 2. Developer Background

The portfolio belongs to Sabir Prajapati, a software developer with professional experience in:

- ASP.NET Core and ASP.NET MVC
- C#
- SQL Server
- React.js
- REST API integration
- Payment gateway integration
- Azure services
- Git and Azure DevOps

The developer is also interested in learning Next.js, Python and AI/LLM development.

Do not invent employment details, project achievements, qualifications or statistics. Use placeholders where information is missing.

## 3. Technology Stack

Use the existing project configuration:

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- React
- Lucide React for icons, if needed

Do not replace the existing framework or unnecessarily change project dependencies.

## 4. Initial Version — Required Features

Build only the following:

### A. Navigation Menu

- Professional navigation bar.
- Developer name or logo on the left.
- Navigation links: Home, About, Projects, Contact.
- Responsive mobile navigation menu.
- Smooth scrolling for section links.
- A simple and attractive visual design.

### B. Homepage / Hero Section

- Professional introduction.
- Name: Sabir Prajapati.
- Role: Software Developer.
- Short introduction highlighting software development experience.
- Primary button: View Projects.
- Secondary button: Contact Me.
- Attractive visual element or developer-themed illustration.
- Clean typography and appropriate spacing.

### C. Basic Page Sections

Create simple placeholder sections for:

- About
- Projects
- Contact

These sections should have appropriate headings and navigation anchors.

Do not add detailed project descriptions or extensive professional content yet.

### D. Footer

Include:

- Developer name.
- Copyright notice.
- GitHub and LinkedIn links as configurable placeholders.

## 5. Design Requirements

The design should be:

- Modern and professional.
- Minimal but visually attractive.
- Responsive on desktop, tablet and mobile.
- Consistent in spacing, typography and colors.
- Suitable for a software developer's personal portfolio.

Use a refined dark theme with subtle accent colors.

Avoid excessive gradients, unnecessary animations, cluttered layouts and oversized elements.

Use reusable React components and maintainable code.

## 6. Code Quality

- Use TypeScript properly.
- Follow Next.js App Router conventions.
- Keep components organized and reusable.
- Use semantic HTML.
- Ensure responsive design.
- Avoid unnecessary dependencies.
- Follow accessibility best practices.
- Keep the implementation easy to understand and extend.

## 7. Deployment Preparation

Prepare the project for deployment to Vercel.

Ensure:

- The development server runs successfully.
- The production build completes successfully.
- There are no TypeScript or ESLint errors.
- No unnecessary backend or API integration is introduced.

The website must be deployable without requiring a database or external API.

## 8. Development Instructions

Before modifying files:

1. Inspect the existing project structure.
2. Understand the installed dependencies and configuration.
3. Preserve the existing Next.js setup.

Then implement the complete initial version.

After implementation:

1. Explain the files created or modified.
2. Explain how to run the project.
3. Run the production build.
4. Fix any errors introduced by your changes.
5. Summarize what has been implemented.

Do not implement additional features outside this scope.
